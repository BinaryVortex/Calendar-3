# Calendar-3

A clean, responsive calendar built with HTML, CSS, and JavaScript.

![Calendar screenshot](./Screenshot%202024-08-25%20174745.png)

## Overview

This is a lightweight web calendar that displays the current month, allows navigation between months, and highlights the current date. It's implemented with vanilla JavaScript and styled using CSS for a modern look.

## Features

- Displays the current month and year
- Navigate to previous and next months
- Highlights today's date
- Responsive layout (works on desktop and mobile)

## Files

- `index.html` — markup and structure
- `style.css` — styles and layout
- `script.js` — calendar logic and interactivity
- `Screenshot 2024-08-25 174745.png` — example screenshot

## How to run

1. Clone the repository:

   git clone https://github.com/BinaryVortex/Calendar-3.git

2. Open `index.html` in your browser (double-click or serve with a static server).
